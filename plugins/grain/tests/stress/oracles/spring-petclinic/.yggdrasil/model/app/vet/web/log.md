One class serves the veterinarian list twice: as a rendered page and as a machine-readable representation of the same data. They are kept together because they answer the same question and must not be able to disagree about the answer. The machine-readable half marks itself on the single method that returns data rather than on the class, so the other method still returns a view name - promoting that marking to the class would silently turn every returned string in the file into a response body. The list is wrapped in a named root object rather than returned as a bare collection so the representation has a stable shape for consumers.
