These two pages exist to be free of the clinic's subject matter. One is the landing page; the other raises an exception on request so that the error page, its localized status messages and its handling can be seen working in a running system rather than only in a test. Keeping the deliberate failure as a reachable page is intentional - an error page that is never rendered outside a test is an error page nobody notices has broken. Neither page may grow a dependency on owners or vets: the moment it does, the plumbing stops being demonstrable on its own.
