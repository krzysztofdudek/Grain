# An answer never invents authority

Everything this product prints is consumed by a model that will act on it, usually without a human
reading it first. That makes a confidently-worded guess more expensive than silence: the model does not
have the standing to doubt it, and the cost of one wrong steer is a change made in the wrong shape,
defended in review by citing this tool.

## Rules

### 1. A stated expectation carries its denominator

Any line that tells the reader what is expected somewhere — "files here import X", "types here are
annotated with Y", "methods here call Z" — must carry the count it rests on, in a form that names both
the conforming population and the total it was drawn from. A bare percentage is not enough: `100%` over
three files and `100%` over three hundred are different claims and must read differently.

The same holds for every derived figure printed beside an answer: a deviation count, a co-change
confidence, a share, a trend. If a number cannot be traced to a population, it does not get printed.

### 2. "No convention here" is a first-class answer, printed as such

When nothing clears the acceptance bar for a place, the answer says so and stops. It does not fall back
on the strongest thing below the bar and present it as an expectation, and it does not pad the silence
with the nearest observation to make the output look useful.

A caller must be able to tell the three apart without guessing:

- there IS an accepted convention here, and it is this;
- there is nothing accepted here — the place is genuinely undecided;
- the question could not be answered at all (no index, no history, no grammar for this file).

The third case names its cause. "No convention" and "could not look" must never render as the same
line.

### 3. Evidence below the bar is labelled as such, wherever it is shown

Some surfaces deliberately show the whole lattice, including rows that did not clear acceptance. Those
rows must be visibly marked as observations rather than accepted conventions, in the row itself and not
only in a header the caller may have truncated away. A model reading a mid-output line must be able to
tell an accepted rule from an observation without having seen the line above it.

### 4. A pointer that is printed must be a pointer that resolves

An exemplar, a carrier, a deviant, a co-change partner: whatever is named must exist at the path and
line given, in the tree the answer was computed from. Where a location is approximate or was truncated,
that is stated rather than rounded into a precise-looking reference.

### 5. Nothing is claimed about a file the analysis could not read

A file with no shipped grammar, a file that failed to parse, a path outside the index: the answer either
excludes it and says so, or does not mention it. It is never counted into a denominator that implies it
was examined, and its absence from a result is never rendered as evidence of anything.

## Why

The product's own position is that a claim exists only if stating it compresses the repository, and that
whether to speak at all is one bounded loss. Both are worth nothing if the printed form of an answer
launders an observation into an expectation. This rule is that position, applied to the sentence rather
than to the statistic: a reader should never have to know how the engine works to know how much to
trust a line.

A place with no convention is a real answer and a useful one. Treat it as freedom rather than as a
failed query, and print it that way.
